About VPNexues

VPNexues is Tamil Nadu's premier organic farm-to-table export company, founded in 2022. We connect farmers directly to consumers and businesses across Singapore, UAE, Europe, and India — eliminating middlemen and delivering the freshest certified organic produce worldwide.

We are building digital infrastructure to power real-world food exports. Our team is lean, ambitious, and deeply mission-driven.

About the Role

As a Next.js Intern, you will work directly with our founding team to build and ship our customer-facing web products — including the B2B ordering portal, public website, and internal dashboards. This is a high-ownership role. You will write production code from day one.

What You'll Be Doing
Frontend Development
  • Build responsive, accessible UI components using Next.js, React, and Tailwind CSS
  • Develop product listing pages, checkout flows, and customer dashboards
  • Implement SEO best practices — metadata, structured data, Core Web Vitals
  • Translate Figma designs into pixel-perfect, production-ready interfaces
Backend & API Integration
  • Integrate REST APIs and third-party services (payments, logistics, CRM)
  • Work with Next.js API routes and server components for SSR/ISR strategies
  • Collaborate on database queries using Supabase or Firebase
Quality & Collaboration
  • Write clean, well-documented code and participate in code reviews via GitHub
  • Communicate async via Slack and join weekly sprint reviews with the team
  • Proactively raise blockers and take ownership of your tasks end-to-end
What We Expect From You
  • Strong grasp of HTML, CSS, and modern JavaScript (ES6+)
  • Hands-on experience or strong coursework in React.js
  • Familiarity with Next.js — pages router or app router
  • Understanding of responsive design and cross-browser compatibility
  • Ability to work independently, manage your time, and communicate clearly
Next.js React HTML / CSS JavaScript ES6+ Tailwind CSS Git / GitHub REST APIs Figma (basic)
Good to Have
  • Experience with TypeScript
  • Familiarity with Supabase, Firebase, or any BaaS platform
  • Basic understanding of SEO and web performance metrics
  • Prior internship, freelance, or personal project experience
  • Interest in agriculture, food exports, or sustainability
