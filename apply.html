About VPNexues

VPNexues is Tamil Nadu's premier organic farm-to-table export company, founded in 2022. We connect farmers directly to consumers and businesses across Singapore, UAE, Europe, and India � eliminating middlemen and delivering the freshest certified organic produce worldwide.

We are building digital infrastructure to power real-world food exports. Our team is lean, ambitious, and deeply mission-driven.

About the Role

As a Full Stack Web Developer Intern, you will work directly with our founding team to build and ship customer-facing web products end to end � Node.js and React on the frontend, Java on the backend, and MongoDB for data. This is a high-ownership role. You will write production code from day one.

What You'll Be Doing
Frontend Development (Node.js + React)
  • Build responsive, accessible UI components using Node.js, React, and modern CSS
  • Develop product listing pages, checkout flows, and customer dashboards
  • Implement SEO best practices � metadata, structured data, Core Web Vitals
  • Translate Figma designs into pixel-perfect, production-ready interfaces
Backend Development (Java)
  • Design and build REST APIs using Java (Spring Boot)
  • Implement business logic, authentication, and third-party integrations (payments, logistics, CRM)
  • Write clean, maintainable, well-documented server-side code
Database & Integration (MongoDB)
  • Model and manage data using MongoDB � schemas, indexes, and aggregation queries
  • Connect frontend and backend systems through REST APIs
  • Write clean, well-documented code and participate in code reviews via GitHub
What We Expect From You
  • Strong grasp of HTML, CSS, and modern JavaScript (ES6+)
  • Hands-on experience or strong coursework in React.js
  • Basic understanding of Node.js and REST APIs
  • Familiarity with Java fundamentals (Spring Boot is a plus)
  • Basic knowledge of MongoDB or any NoSQL database
